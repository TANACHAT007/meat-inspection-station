หลักการทำงาน (stop-and-capture)

ESP32 คุมสายพานด้วยตำแหน่งจากเอนโค้ดเดอร์ ส่วนโปรแกรมบนคอมพิวเตอร์ถ่ายภาพและวิเคราะห์

  1. วางแพ็ก โฟโต้เซนเซอร์ E18-D80NK ตรวจพบถาด
  2. เดินเข้ากล้อง สายพานเดินระยะที่ตั้งไว้ (ปรับด้วย DIST) จนถาดหยุดกลางภาพกล้องในอุโมงค์
  3. ถ่ายภาพ ไฟขาว (และ NIR 850 / UV 365 ในชุด Plus) ติดทีละแบบ กล้องถ่ายพร้อมแผ่นสีอ้างอิง
  4. วิเคราะห์ภาพ แปลงเป็นแสงเชิงเส้น ปรับด้วยการ์ดเทา 18% แยกเนื้อด้วย Lab แยกไขมันด้วย Otsu บนแกน a* คำนวณ % marbling สี L*a*b* อัตราส่วนสีน้ำตาล
  5. อ่านเซนเซอร์ เลื่อนถาดไปใต้ AS7341 / MLX90614 / MQ-137 รอ 1.2 วินาที
  6. สรุปผล สถานะ ok / watch / alarm (กฎเริ่มต้น ต้องปรับเทียบ) บันทึก CSV และภาพ annotated แล้วปล่อยถาดออก

E-stop ตัดไฟ 12 V แบบฮาร์ดแวร์เท่านั้น ไม่ใช่ฟังก์ชันความปลอดภัยที่รับรอง ไฟบ้านอยู่ในกล่อง A เท่านั้น ให้ช่างไฟตรวจ

สถานะซอฟต์แวร์ firmware คอมไพล์ผ่านบน ESP32 core 3.3.12 (ใช้แฟลช 26%) และโปรแกรม Python ผ่าน unit test 5 ข้อบนภาพสังเคราะห์ ยังไม่ได้ทดสอบกับฮาร์ดแวร์จริง
